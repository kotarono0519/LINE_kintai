# 交通費・経費清算書を今月分にする

`~/Desktop/月末書類とか/交通費` の交通費・経費清算書に、対象月（言われなければ今月）の分があるかを見る。無ければ、最新月のファイルを複製して対象月の分を作り、右上の年月だけを直す。

## 決まり

- 複製元は、ファイル名の「YYYY年M月分」がいちばん新しいもの。新しい名前は、その部分だけを対象月に変える（例: `…_2026年9月分_v4.1.xlsx` → `…_2026年10月分_v4.1.xlsx`）
- 対象月のファイルが既にあれば、何もしない。上書きしない
- 直すのは「旅費交通費清算書」シートの右上の年月（セル R2）だけ。中身は月の 1 日の日付で、表示が「2026年10月」になる
  - 表の日付（月の 1 日から並ぶ列）と「年月抽出」の年・月は R2 から計算される。開いたときに計算し直す設定を入れるので、Excel で開くと対象月の日付に切り替わる（閉じるとき保存するか聞かれるのはこのため）
- 交通費の行など、前の月の中身はそのまま残す（消すのは本人）
- 書式を崩さないため、Excel のファイルの中身を直接書き換える。Excel では開かない（本人が開いているファイルに割り込まない）

## 手順

### 1. 実行する

```shell
python3 ~/dev/kintai/.claude/skills/expense-sheet/next_month.py            # 今月分
python3 ~/dev/kintai/.claude/skills/expense-sheet/next_month.py --month 2026-11   # 月を指定
```

- 「既にある: …」と出たら、対象月のファイルは既にある。そのまま伝えて終わる
- 「R2 が複製元の月の 1 日になっていない」と出たら、ひな形の作りが変わっている。直さずに止めて伝える
- 「注意: 複製元は今 Excel で開かれている」と出たら、保存していない変更は複製に入っていないことを伝える

### 2. 伝える

作ったファイルの名前と「年月を ○月 → ○月 に直した」ことを短く伝える。Excel で開いて右上の年月を確かめてもらう。
