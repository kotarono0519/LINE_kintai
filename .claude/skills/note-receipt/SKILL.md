# note の領収書を PDF で取る

note の購入・チップ履歴（https://note.com/settings/purchase_history ）から最新月の領収書を取り、PDF にしてダウンロードフォルダ（`~/Downloads`）に置く。
画面の操作は Chrome（Claude in Chrome）で行う。

note の領収書ページにはダウンロードボタンが無く、「このページを印刷してご利用ください」とだけある。ブラウザの印刷画面は操作を止めてしまうので使わない。代わりに、領収書の部分だけを HTML として保存させ、Mac 側で画面なしの Chrome に PDF へ印刷させる。

## 決まり

- 保存名は `領収書_<支払先>_<年-月>.pdf`（例: `領収書_AI駆動開発研究部_2026-10.pdf`）。月は領収書の購入日の月（DEC-0042）
  - 支払先は、購入・チップ履歴の行の 2 行目「AI駆動開発研究部 / スタンダードプラン」の ` / ` より前
- 同じ名前のファイルがあれば、上書きも改名もしない。そこで止めて本人に伝える（月の付いていない古い `領収書_AI駆動開発研究部.pdf` などは触らない）
- 宛名（画面では書き換えられる）は、言われなければそのまま（kotaro 様）
- ログインは代わりにしない。ログインしていなければ「ログインしてから、もう一度頼んでください」と伝えて終わる
- 途中で作った HTML は、PDF ができたら消す。PDF 以外はダウンロードフォルダに残さない

## 手順

### 1. 最新月の行を見つける

1. 新しいタブで https://note.com/settings/purchase_history を開く
2. 画面の文字を読む（ページの文字を取る道具）。最初は今月が選ばれている
3. その月に行が無ければ、月の選択を 1 か月ずつ前へ戻して、行がある月を探す（12 か月戻っても無ければ止めて伝える）
4. 行が複数あるときは、どれも取る（1 行 = 1 枚の PDF）。名前が重なる（同じ支払先・同じ月）ときは、本人に伝えてから進める

### 2. 領収書ページを開く

1. 行の右端の「…」を押し、出てきた「領収書」を押す
2. 新しいタブで `https://note.com/receipt/<取引ID>?t=receipt` が開く。そのタブに切り替える

### 3. 領収書の部分を HTML で保存させる

このスキルの `extract.js` の中身を、そのタブでそのまま実行する（ページで JavaScript を動かす道具）。
戻り値の `file`（保存されたファイル名）・`month`（年-月）・`text`（領収書の文字）を控える。

- `error` が返ったら、ページの作りが変わっている。止めて伝える
- `month` が `null`（購入日が読めなかった）なら、名前を決められない。保存された HTML を消して止め、伝える
- 保存は 1 タブにつき 1 回だけにする。同じタブで 2 回目を保存させると、Chrome が「複数ファイルのダウンロード」の許可を求めて止まる（その場合は本人に許可してもらうか、領収書のタブを開き直す）

### 4. PDF にする

```shell
~/dev/kintai/.claude/skills/note-receipt/to-pdf.sh \
  "$HOME/Downloads/<file>" \
  "$HOME/Downloads/領収書_<支払先>_<month>.pdf"
```

- 終了コード 2 は「同じ名前のファイルがある」。上書きせず、本人に伝える
- できたら `~/Downloads/<file>`（途中の HTML）を消す

### 5. 中身を確かめる

PDF を画像にして目で見る（`qlmanage -t -s 1200 -o <作業用フォルダ> <PDF>` で PNG ができる）。
取引ID・「領収書」の見出し・購入日・宛名・内容・金額・内訳・領収者・運営会社が載っていて、印刷ボタンやブラウザの拡張の表示が写っていないこと。

### 6. 片づけて伝える

開いたタブを閉じる。保存した PDF の名前と、購入日・内容・金額を短く伝える。
